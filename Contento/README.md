### 1. Open Secure Save

Open the Secure Save website using a modern browser. HTTPS is required for browser-based encryption.

### 2. Create Your Vault Password (First Use)

**The first time you open Secure Save, enter a new password of your choice.** There is no predefined password.

1. Open Secure Save.
2. Choose a strong, unique password.
3. Enter it into the password field and click **Unlock**.
4. Start typing or paste your content into the editor.
5. Wait until the application confirms that your content has been encrypted and saved.

Your first save creates your encrypted vault in Pastefy. Remember the password because it is required to decrypt your content on future visits and other devices.

### 3. Unlock Your Existing Vault

After creating your vault:

1. Open Secure Save on any device.
2. Enter the same password you originally chose.
3. Click **Unlock**.
4. Wait for your saved content to load and decrypt.

Use the same website configuration and Pastefy paste ID on every device to access the same vault.

### 4. Change or Reset Your Vault Password

Secure Save does not currently provide a built-in password-change or password-recovery feature. However, you can reset the vault manually through Pastefy.

**Warning: Clearing the Pastefy content permanently removes the existing saved vault data unless you have a backup.**

1. Open the Pastefy website and sign in if required.
2. Locate the paste used by your Secure Save installation.
3. Back up any content you want to keep.
4. Edit the paste and remove its existing content, leaving it empty. Save the changes.
5. Return to Secure Save and refresh the page.
6. Enter your new password.
7. Add your content and wait for the encrypted save confirmation.

The application will treat the empty paste as a new vault. Your next save will encrypt the content using a key derived from your new password.

**Important:** Clearing the Pastefy content does not change the old password into the new one or recover previously encrypted data. It starts a new vault, and any old encrypted content that was not backed up may become unrecoverable.

## ❓ Frequently Asked Questions

### What password should I use the first time?

Choose your own strong password. Secure Save does not provide a default password. Your first save creates the encrypted vault.

### How can I change my password?

There is no built-in password-change feature yet. Back up any important content, clear the existing paste content directly on Pastefy's website, and create a new vault using your new password.

### Will resetting my password preserve my saved text?

No. The manual reset method starts a new, empty vault. Existing content will be lost unless you back it up first. To preserve existing data while changing passwords, a separate decrypt-and-re-encrypt migration feature would be needed.

### What happens if I forget my password?

There is no password recovery mechanism in the current implementation. If you forget your password, you generally cannot decrypt the existing vault. If you intend to reset it, remember that clearing the paste will discard the existing encrypted data.
